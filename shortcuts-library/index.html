How it works

  1. Add anysite-mcp to your agent once, for example in Claude Code: claude mcp add anysite -- npx -y anysite-mcp
  2. Add a shortcut from this page with its command, e.g. npx -y anysite-mcp add github.com/trending. Leave off /name to add every shortcut for that site.
  3. Restart your agent. The shortcut is now a tool named <site>_<name>, such as github_com_trending.

A shortcut is only a list of steps for the web_* tools (open, click, type, read, extract and so on). No code runs, and it can't do anything the agent couldn't already do on that site. Read the steps before you add one all the same. Already have a shortcut with that name? Add --force to replace it.

Share a shortcut

Saved a shortcut that works? Ask your agent for its JSON with web_list_shortcuts (give it site and name), paste it below, and this page checks it and turns it into a pre-filled GitHub issue or a pull request to library/<site>.json.
